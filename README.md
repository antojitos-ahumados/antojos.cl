# antojos.cl

Este repositorio contiene el código fuente de la página «próximamente» de [antojos.cl](https://antojos.cl) (Antojitos Ahumados, sitio de venta por mayor).

Se publica con Cloudflare Pages.

Junto a la página van los archivos habituales del sitio: `robots.txt`, `sitemap.xml`, `favicon.svg`, `favicon.ico`, `404.html`, `_headers` y `.well-known/security.txt`.

El sitio Jekyll anterior se conserva en la rama `archivo-sitio-jekyll-2017`.
